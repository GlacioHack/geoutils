# The {class}`vct <geoutils.VectorAccessor>` accessor

The {class}`vct <geoutils.VectorAccessor>` accessor exposes GeoUtils vector methods on {class}`geopandas.GeoDataFrame` objects.

It mirrors the GeoUtils-specific API of {class}`~geoutils.Vector`; native GeoPandas methods remain available directly on the dataframe.
