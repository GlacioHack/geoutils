# DataArray.pc accessor

The {class}`DataArray.pc <geoutils.DataArrayPointCloudAccessor>` accessor exposes GeoUtils point cloud methods on {class}`xarray.DataArray` objects.

It mirrors the API of {class}`~geoutils.PointCloud`; native Xarray methods remain available directly on the DataArray.
